# Research Frameworks Matrix

Select the appropriate framework and depth level based on the nature of the research question.

## 1. Question Type Frameworks

| Framework | Best Used For | Key Objective |
| :--- | :--- | :--- |
| **Verification** | Fact-checking claims, validating statistics, auditing technical capabilities | Establish empirical truth and accuracy thresholds. |
| **Causal** | Explaining why a system or trend behaves as it does | Map underlying mechanisms, feedback loops, and root causes. |
| **Scenario** | Evaluating future trajectories, technological shifts, market trends | Construct probability-weighted potential futures and catalysts. |
| **Decision** | Evaluating options for strategic choice or investment | Provide decision-grade comparative risk/reward tradeoffs. |

## 2. Depth Levels

| Depth Level | Scope & Sources | Output Expectation |
| :--- | :--- | :--- |
| **Quick Scan** | 3-5 key sources per lens | Concise core findings, surface-level tensions. |
| **Standard** | 5-10 primary/secondary sources per lens | Thorough lens-by-lens analysis, explicit contradiction pass. |
| **Deep Dive** | 10+ Tier 1/2 sources per lens | Exhaustive prose, rigorous data extraction, complete bibliography. |
